kube-nat docs v0.1.x

Replace AWS NAT Gateway with zonal EC2 NAT.

kube-nat runs a Kubernetes-native NAT agent on EC2 worker nodes, manages route tables per AZ, and exposes a live operational dashboard with failover visibility and per-node health.

GitHub Full README Releases

What it does

One active agent per AZ owns subnet default routes and performs SNAT with the instance EIP.

Why it exists

Reduce fixed NAT Gateway spend, avoid cross-AZ transfer penalties, and gain higher-resolution observability.

How it fails over

Spot interruption notices, SIGTERM handling, and peer heartbeats converge route ownership within hundreds of milliseconds.

Quick start

helm upgrade --install kube-nat \ oci://ghcr.io/mfeldheim/kube-nat/helm/kube-nat \ --namespace kube-nat \ --create-namespace \ --set image.tag=v0.1.18

Dashboard highlights

  • Header shows the dashboard server version.
  • Each node tile shows instance type, instance ID, owned route tables, and the running agent version.
  • Footer links back to docs and the GitHub repository.
